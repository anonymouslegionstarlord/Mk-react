# React Practice Collection

A collection of small React projects covering rendering, state, props, Tailwind CSS, and custom rendering concepts.

| Directory | Topic |
|---|---|
| `01basicreact` | Create React App fundamentals |
| `01vitereact` | Vite rendering and React elements |
| `02counter` | Bounded state updates |
| `03tailwindprops` | Reusable cards, props, and Tailwind CSS |
| `04colorchange` | Interactive background color state |
| `CustomReact` | A minimal custom renderer exercise |

## Run any packaged project

```bash
cd 04colorchange
npm install
npm run dev
```

## Validate

```bash
npm run build
npm run lint
```

Use Node.js 20 or newer. Each directory is independent and has its own dependencies.
